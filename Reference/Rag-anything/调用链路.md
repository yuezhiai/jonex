# Rag-Anything 视频处理 → LightRAG 全调用链路

## 概述

视频从文件输入到进入 LightRAG 知识图谱，共经历 **4 个阶段**：文件解析（极轻量）→ VideoModalProcessor 主处理（ASR+关键帧+VLM+MapReduce）→ 转 LightRAG Chunk → 知识图谱入库。

---

## 阶段 2：VideoModalProcessor 主处理

### 初始化：`raganything.py:356-413` — `_initialize_processors()`

当 `config.enable_video_processing=True` 时创建 `VideoModalProcessor`：

| 依赖 | 来源 | 说明 |
|------|------|------|
| `vlm_model_func` | 自动从 VISION_BINDING_HOST 创建或用户传入 | 帧图描述 |
| `asr_backend` | 自动从 ASR 注册表创建或用户传入 | 音频转写 |
| `image_transport` | 配置 COS 时自动创建 | 帧图上传 URL 传输 |
| `tokenizer` | 来自 `lightrag.tokenizer` | token 计数 |
| `modal_caption_func` | `self.llm_model_func` | 文本摘要 LLM |

### 主入口：`video_processor.py:74` — `generate_description_only()`

按顺序执行以下 8 个子步骤：

---

#### 步骤 A：身份计算（行 78-86）

| 标识 | 方法 | 用途 |
|------|------|------|
| `_quick_video_hash` | xxhash64(文件头 64KB + 尾 64KB + 中间 256B) | 物理文件标识，输出目录 |
| `_semantic_video_fingerprint` | SHA-256(时长 + 3 帧感知哈希) | 跨重编码稳定，帧目录标识 |

- 写入 `modal_content["_video_quick_hash"]` 和 `modal_content["_video_source_id"]`

---

#### 步骤 B：音频提取 + ASR（行 92-104）

```python
video_processor.py:292  _extract_audio() → FFmpeg
  ffmpeg -i video.mp4 -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav

video_processor.py:312  _transcribe() → ASR backend
  asr_backend.transcribe(audio.wav)
```

- 动态超时：`max(120s, 视频时长 × 3)`
- 临时 `audio.wav` 在处理完后删除
- **无音轨时**：返回空转录，`audio_available=False`，后续降级

---

#### 步骤 C：混合关键帧提取（行 107，328-376）

```python
video_processor.py:328  _extract_keyframes()
```

**四种算法**，通过 `config.video_keyframe_algorithm` 配置：

| 算法 | 实现位置 | 方式 | 特点 |
|------|----------|------|------|
| `interval` | `_interval_timestamps()` | 固定间隔 `video_keyframe_interval` 秒 | 最快速、最可预测 |
| `scene` | `_detect_scenes()` | ffprobe `select='gt(scene,0.4)'` | 内容感知、场景边界准确 |
| `iframes` | `_iframe_timestamps()` | 读取编码 I 帧 `pts_time`+`pict_type` | 元数据级、极快（无需像素解码） |
| `hybrid`（默认） | `_hybrid_timestamps()` | I 帧 + 间隔填充大间隙 | 保证密度 + 自然切点 |

**兜底逻辑**（行 365-368）：
- 如果算法提取帧数 < `min_frames`（时长/间隔），回退到 interval
- 如果第一帧 > 0.5s，插入 0.0s 帧

**帧上限控制**（行 371，`_cap_timestamps()`）：
- 最多 `video_max_frames` 帧（默认 50），均匀降采样

**实际提取**（行 489-540，`_extract_frame_images()`）：
- `ffmpeg -accurate_seek -ss {ts} -i {video} -frames:v 1 -q:v 2` 提取 .jpg
- 100ms 时间桶去重（同一桶的帧只提取第一帧）
- 缓存：已提取的帧文件跳过（基于文件名检测）

输出目录：`{parser_output_dir}/video_frames/{semantic_video_id}/`

---

#### 步骤 D：VLM 逐帧描述（行 117-154，599-695）

**调用前**：帧图可选通过 `image_transport`（COS）上传获取公网 URL

**传输策略**（四模式）：

```python
# video_processor.py:118-154
if prep.transport_available:          → VLM URL 模式（首选）
elif prep.fatal_error + VLM base64:   → 降级 base64
elif prep.fatal_error + no base64:    → 跳过视觉分析
else + VLM base64:                    → 直接 base64
```

**核心逻辑** `_describe_frames()`（行 599-695）：

- 并发控制：`config.max_parallel_vlm`（默认 2），使用 `asyncio.Semaphore`
- 每帧 VLM prompt：要求分离 `===OCR===` 和 `===SCENE===`
- **重试机制（3 次）**：
  - 不可重试：400/401/403/404/auth/not found（`_is_retryable_vlm_error`）
  - 可重试：timeout/429/5xx/connection（指数退避 1s, 2s, 4s）
- 解析 VLM 输出（`_parse_vlm_output`）：正则提取 `===OCR===...===SCENE===` 结构
- 结果写入 frame dict：`description`、`ocr_text`、`scene_description`、`vlm_error`

---

#### 步骤 E：时间对齐 — 独占帧归属（行 890-926）

```python
video_processor.py:890  _align_frames_to_segments(segments, keyframes)
```

**算法**：每个 segment 计算 `(start_time + end_time) / 2` 作为中点。每个 frame 通过 `bisect_left` 找到最近中点的 segment，写入 `frame["owner_segment"]`。

**保证**：一帧严格属于一个 segment，无共享、无遗漏。

**无音轨降级**（行 161-182）：所有帧描述拼成伪转录，合并为单个 segment。

---

#### 步骤 F：视觉浓缩（行 781-822）

```python
video_processor.py:781  _condense_frame_descriptions(frames)
```

| 条件 | 策略 |
|------|------|
| 有 OCR 且 > 5 字符 | 过滤非信息行（菜单/纯数字/纯大写缩写等），`;` 拼接，截断 120 字符 |
| 无 OCR | LLM 压缩为一行 ≤ 30 词 |
| 两者 | 提取 `extractive_terms`：OCR 分词 + scene_description 分词 |

结果：`frame["condensed"]`、`frame["extractive_terms"]`

---

#### 步骤 G：MapReduce 摘要（行 930-1035）

```
segments → batch[8] → LLM 分组摘要 → 递归 reduce → 全局合成
```

**1. 分组摘要**（行 946-972）：
- `video_summarize_batch_size`=8，`video_summarize_max_batches`=20
- 提示词 `video_group_summary_prompt`：摘要视频片段主题、决策、行动项

**2. 递归归约**（行 975-992）：
- 多轮合并直到只剩 1 个摘要
- 每轮同样 batch_size=8

**3. 全局合成**（行 996-1034）：
- 提示词 `video_global_prompt`（`prompt.py:486`）
- 输出必须是 JSON：
  ```json
  {
    "detailed_description": "完整综合描述...",
    "entity_info": {
      "entity_name": "...",
      "entity_type": "meeting|lecture|presentation|...",
      "summary": "100 字摘要"
    }
  }
  ```
- 解析失败时 fallback：`entity_type = "unknown"`

**结果写入 entity_info**：
```python
entity_info["video_source_id"] = semantic_video_id
entity_info["chunk_count"] = len(segments)
entity_info["transcript_preview"] = transcript[:1000]
```

```python
modal_content["_audio_segments"] = segments   # 带时间戳、帧、摘要
modal_content["_asr_result"] = asr_result     # 原始转录
modal_content["_video_keyframes"] = keyframes # 所有帧
```

## 阶段 3：转成 LightRAG Chunk

### 代码位置：`processor.py:1075` — `_convert_to_lightrag_chunks_type_aware()`

**视频分支**：`processor.py:1134`（与 audio 同模式）

### 每个 segment → 一个 chunk

```python
for seg_idx, seg in enumerate(segments):
    # 跳过空段（无文本无帧）
    if not seg.get("text", "").strip() and not seg.get("frames"):
        continue

    # 帧处理：只取 owner_segment==seg_idx 的帧，去重，最大 5 帧
    owned_frames = _sample_frames(owned_frames, max_frames=5)
```

### Chunk ID

基于时间戳，内容稳定，重复处理可覆盖：

```
compute_mdhash_id(
    f"{video_source_id}:{int(start_ms)}-{int(end_ms)}",
    prefix="chunk-"
)
```

### Chunk 数据结构（`processor.py:1197-1222`）

| 字段 | 类型 | 说明 |
|------|------|------|
| `content` | str | 格式化文本模板 |
| `tokens` | int | token 数 |
| `full_doc_id` | str | 文档 ID |
| `is_multimodal` | bool | `True` |
| `original_type` | str | `"video"` |
| `modal_entity_name` | str | 视频实体名 |
| `start_time` / `end_time` | float | segment 时间范围 |
| `source_segment_indices` | list[int] | 原始 ASR segment 索引 |
| `relative_position` | float | 视频中的相对位置 [0,1] |
| `speaker_labels` | list[str] | 发言人标签 |
| `group_summary` | str | 分组摘要文本 |
| `video_source_id` | str | 视频语义指纹 |
| `frame_ids` | list[str] | 帧 ID 列表 |
| `frame_paths` | list[str] | 帧文件路径列表 |
| `frame_times` | list[float] | 帧时间戳列表 |
| `frame_descriptions` | list[str] | 帧 VLM 描述列表 |
| `frame_condensed` | list[str] | 帧浓缩描述列表 |
| `frame_ocr_texts` | list[str] | 帧 OCR 文本列表 |
| `frame_extractive_terms` | list[list[str]] | 帧关键词列表 |

### Chunk 文本模板

```python
# prompt.py:458
PROMPTS["video_chunk"] = """## Video Segment [{start_time:.0f}s–{end_time:.0f}s]

- **File**: {file_name}
- **Segment**: {segment_index}/{total_segments}
- **Language**: {language}
- **Keyframes**: {frame_count}

### Visual Context
{frame_descriptions}

### Transcript
{transcript}"""
```

### Token 预算控制（`processor.py:1184-1195`）

- 上限 `video_chunk_token_size`（默认 600）
- 超限时**从末尾删除帧描述**，直到 token ≤ 上限
- 这说明帧的描述可能会被截断以保证 transcript 完整


## 最终知识图谱结构

```
video.mp4 (LightRAG document)
  └── Video Entity (entity_type: "lecture"/"meeting"/"presentation"/etc.)
        │
        ├── Temporal Chunk [0s-30s]
        │     ├── content: "## Video Segment [0s-30s]\n\n### Visual Context\n..."
        │     ├── transcript: "大家好，今天开始会议..."
        │     ├── frame_descriptions: ["会议标题幻灯片", "发言人站立"]
        │     ├── frame_ocr_texts: ["2024年度总结", "营收增长20%"]
        │     └── extracted_entities: [张三, 项目A, Q4目标]
        │
        ├── Temporal Chunk [30s-60s]
        │     ├── content: "## Video Segment [30s-60s]\n\n### Visual Context\n..."
        │     ├── transcript: "项目A的进展情况如下..."
        │     ├── frame_descriptions: ["柱状图", "代码演示"]
        │     ├── frame_ocr_texts: ["Q1 50%", "Q2 75%"]
        │     └── extracted_entities: [项目A, 完成率, 李四]
        │           └── belongs_to → Video Entity
        │
        └── Temporal Chunk [60s-90s]
              └── ...
```

**检索时**：用户自然语言查询 → LightRAG 向量检索 → 找到相关 temporal chunks → 返回 transcript + 帧视觉描述 → 可选的 VLM 增强回答。

## 关键配置项

所有视频相关配置在 `RAGAnythingConfig`（`config.py`）中定义：

| 配置项 | 默认值 | 作用 |
|--------|--------|------|
| `enable_video_processing` | True | 开关 |
| `video_keyframe_algorithm` | `"hybrid"` | 关键帧算法 |
| `video_keyframe_interval` | 10 | 间隔算法秒数 |
| `video_max_frames` | 50 | 最大关键帧数 |
| `video_chunk_token_size` | 600 | 每 chunk token 上限 |
| `video_summarize_batch_size` | 8 | MapReduce 批次大小 |
| `video_summarize_max_batches` | 20 | MapReduce 最大批次 |
| `video_vlm_contextual_prompt` | False | 是否启用上下文 VLM prompt（提前后帧时间） |
| `max_parallel_vlm` | 2 | VLM 并发数 |
| `vlm_timeout` | 60 | VLM 超时秒数 |
| `parser_output_dir` | `"output"` | 帧图/缓存输出目录 |
